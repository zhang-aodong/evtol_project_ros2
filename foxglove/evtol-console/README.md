# EVTOL Simulation Console

Connect to the manager's Foxglove WebSocket, then add the panel
**EVTOL Simulation Console**. All changes and launch actions use the
`/simulation/console` JSON service. No shell commands run inside the panel.

Build: `npm ci`, `npm run typecheck`, `npm run package`.
Local desktop installation: `npm run local-install`.
See the project's Chinese console tutorial for setup and operating rules.
