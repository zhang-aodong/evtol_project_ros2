# 目标定位实现验证记录

日期：2026-11-06。平台：本机 Windows 11，UE 4.27 / Cosys-AirSim，原生 ROS2 Jazzy；UE 游戏保持运行，主机控制网关使用 shadow。

## 编译与测试

- 八个 ROS 功能包已构建通过，包含新增 C/C++/Python 消息类型支持。
- 完整 `python -m unittest discover -s tests -v`：47 项通过，9.866 s。
- 新增测试覆盖时序插值、运动补偿、遮挡、同类目标聚类、空深度、重复扫描、跟踪、路径坐标、CPA、制动预算、节点测量与仿真时钟暂停时的停车检查。
- 模型通过独立 Python 3.11 + CUDA 实际加载和共享内存推理；SHA256 与旧工程一致。两轮 640×480 零图测试热身后约 6–13 ms，不作为识别准确率证据；最近一轮保存在 `reports/model_smoke.json`。

## 真实 UE 数据链路

报告：`reports/targeting_live_final.json`，观察窗口 30.006 s，Foxglove 预览和桥接同时运行。订阅发现需要时间，频率由各话题首次至末次收到的消息计算。

| 话题 | 实测平均频率 | 本窗口最大接收间隔 |
| --- | ---: | ---: |
| LiDAR | 20.01 Hz | 76.6 ms |
| 起点 ENU 自机状态 | 20.00 Hz | 53.9 ms |
| 模型语义 | 19.38 Hz | 65.8 ms |
| 三维测量 | 19.40 Hz | 102.7 ms |
| 预测轨迹 | 19.99 Hz | 60.3 ms |
| 安全速度指令 | 50.06 Hz | 28.4 ms |
| 风险状态 | 50.06 Hz | 36.8 ms |

535 个实际模型语义帧，单次推理中位数 8.19 ms。521 个三维测量输出中 358 个包含目标，最多 3 个目标；其余 163 个明确报告 `NO_TARGET_DEPTH`。538 个轨迹输出中 532 个非空。这些计数证明模型与深度链路产生真实输出，**不是有真值标注的检出率或正确目标数量**。

语义帧采集年龄 P50 / P95 为 332 / 382 ms，三维测量采集年龄为 392 / 444 ms。年龄相对 20 Hz `/clock`，存在约一个周期量化误差；雷达几毫秒负年龄是这种量化的表现，不代表时间已经精确同步。相机保持原有 200 ms 排序缓冲，另有采集、传输与算法等待，本版不满足 30 ms 完整视觉延迟。

调试中发现启用仿真时间时 ROS Timer 受 20 Hz `/clock` 限制，已将避障定时器改为 steady clock，实际检查恢复约 50 Hz；状态/点云年龄和指令 TTL 继续使用采集时间及独立墙钟看门狗。视觉进程启用 Windows 1 ms 调度并限制 OpenCV 线程，实测语义从初版约 16 Hz 提高至约 19.4 Hz，仍不能宣称严格 20 Hz 全程无丢帧。

主机在地面，默认任务含抬高航点，绝大多数安全指令为 `unobserved_direction_stop`；这是未观测方向停车，不能将该测试称为闭环避障成功。安全节点累计错误计数含启动等待和偶发位姿未夹取等停车事件，最终诊断为 streaming。完整协议验收仍需单独实验。

## 场景控制验证

实时场景测试入口 `scripts/smoke_actors_live.py --config config/targeting.yaml` 会主动控制 Drone2 与 Pedestrian_2，测试结束通过 `/scenario/stop` 服务完成降落和释放控制；主机继续保持 shadow。它生成专用 `reports/actors_smoke_fixture.yaml`，不会改写默认路径。

实测结果记录在 `reports/actors_live_smoke.json`：Drone2 最大三维位移 2.90 m、最大水平位移 1.33 m，行人起终点位移 2.55 m；停止服务 `cleanup_success=true`，最终 `landed_state=0`。这是单障碍机和单行人的路径/清理冒烟测试，不是四机同时运行的精度与性能验收。

测试过程中发现 SimpleFlight 可能已经离地稳定，但 takeoff 的位置收敛任务返回超时。已加入与旧工程相同的已离地恢复方向，并要求实际上升至少 0.5 m、低速度和 Flying 状态；未满足条件仍拒绝继续路径。到点按真实位置误差检查，默认 0.5 m，超出则最多重试三次。降落清理按成功 land、运动稳定、成功 disarm、确认 Landed 的顺序执行，失败会通过服务返回 false。
