# YOLO26 语义模型更新

当前在线模型已更新为新微调的七类 YOLO26n 语义模型，项目内文件为 `models/best.pt`。现有 `config/targeting.yaml` 和导航验证配置均继续使用该相对路径。无需重新编译，也无需引用外部训练目录。

Foxglove 管理面板中按原流程启动 ROS 程序即可加载新权重。若更新前已有 ROS 视觉节点运行，需要先正常停止 ROS，再重新启动；仅刷新 Foxglove 不会重新加载模型。终端启动流程和 UE 设置保持不变。

类别编号仍为 0 背景、1 飞机、2 高层建筑、3 行人、4 地面、5 跑道、6 无人机。保留项目自带的 `models/semantic_runtime`；不要用普通 pip Ultralytics 替换该自定义语义运行库。训练输入 1024，在线输入尺寸沿用用户配置（Foxglove 面板当前配置为 960）；训练指标不能直接当作在线实时检测成功率。

同一 UE 地图独立测试集（439 张、1024 输入）上，整体 mIoU 从 77.65% 提升到 89.55%，无人机 IoU 从 45.24% 提升到 75.11%，无人机像素召回率从 66.97% 提升到 87.66%。尚未在本次模型切换后进行实时飞行避障验收。

模型来源、SHA256 和测试指标见 `models/manifest.json`，安装记录见 `reports/semantic_model_install.json`。原权重和原 manifest 已备份在该记录的 backup 路径。

回滚时先停止 ROS 视觉节点，再将备份目录中的 `best.pt` 和 `manifest.json` 复制回 `models/`，然后重新启动 ROS。迁移到另一台机器时，携带完整 `models/` 目录，按项目文档配置 ModelPython 即可；不需要原机器的训练数据目录。
