## 控制策略

正常飞行时，以视觉目标检测框和 LiDAR 投影定位得到的融合轨迹作为障碍输入。
局部路径按 2 Hz 更新，在采样参考航段周围运行水平优先、允许三维绕行的 A*。
20 Hz 速度安全层检查障碍运动预测、制动距离和可执行速度；远处告警统计不直接成为应急控制。

机体原点距离原始 LiDAR 回波不超过默认 2 m 时，且网关已处于新鲜的 `flying` 状态，
进入独立 `lidar_emergency` 状态：

1. 暂停路径请求及航点到达计时，保留原航点编号。已有异步规划结果作废，不再用于控制。
2. 清空局部规划路径话题，状态中的 `planning_paused=true`、`planning_hz=0`。
3. 使用全向点云约束，检查前后左右、上下及斜向候选速度；不追逐航点。
4. 触发半径仍为 2 m。检查逃逸方向时使用默认 6 m 内的已测点云，以验证较快脱离的制动空间。
   应急速度上限为 `min(raw_emergency.escape_speed_mps, control.max_speed_mps)`，默认期望值 1.5 m/s。
   避让计算保留响应延迟、测量年龄、加速度和实际运动段约束，不会瞬间改变实际速度。
5. 原始回波约束独立于视觉类别。融合障碍仍参与碰撞检查。无满足全部预测约束的候选时，
   仅允许改善最坏预测净空、满足点云制动和融合目标物理包络的尽力脱离，明确标为
   `lidar_emergency_best_effort`；无法改善时制动并控高，不能将其标为保证安全。
6. 禁止以应急为理由请求降落。应急下降受地面净空和进入应急时的高度约束，防止持续下沉。
7. 回波离开触发半径加默认 0.4 m 滞回范围后，连续 0.5 s 新鲜扫描确认脱险，
   从当前位置重规划到原航点。应急中经过某航点不算到达，更不能跳到末点降落。

起飞阶段保留原支撑面与上方障碍检查；最终着陆交接保留原着陆走廊检查。

## 故障保护与状态

原始方向编号保留在 JSON 风险列表中，并标记 `source=raw_lidar`。
`Risk.track_id` 对无实例身份的原始回波使用 0，实际融合轨迹保留自身非负 ID。

执行网关遇到过期指令或零速度制动时，使用 AirSim `moveByVelocityZ` 保持锁存高度。
管理程序发现飞行中的算法退出，会请求 `/drone1/control/failsafe_hold`，锁存故障控高，
保留控制网关和 API 控制权，日志和运行总览显示 `runtime_fault`，需明确停止/重启。
这不等于故障后继续完成任务。强制结束仍按用户要求终止自有进程。

Foxglove「避障实验 → 起飞后近距雷达紧急避障」可设置触发距离、期望应急速度、
解除距离滞回和连续脱险确认时间。参数保存后下次启动 ROS 生效；配置导入导出包含这些参数。
旧 v8 配置缺少新字段时补充默认值，不修改用户的航点或本地配置文件。

```yaml
safety:
  raw_emergency:
    enabled: true
    radius_m: 2.0
    escape_speed_mps: 1.5
    self_exclusion_m: 0.25
    max_range_rate_mps: 12.0
    range_history_s: 0.25
    release_margin_m: 0.4
    release_hold_s: 0.5
```

## 复验

激活工程 ROS 2 环境后：

```powershell
python .\tests\probe_flight_layers.py --case raw_side --height 3 --side-speed 2.4 --seconds 30 --label emergency_side_check
python .\tests\probe_flight_layers.py --case raw_resume --height 3 --side-speed 0.8 --seconds 50 --label emergency_resume_check
```

这些脚本仅管理自己启动的 UE / ROS，使用隔离 ROS 域，测试后恢复会话原点，不覆盖本地配置。
运行前应确认 AirSim 端口未被其他仿真实例占用。检查报告的 `airborne_collisions`、
`emergency_progression_violations`、`completed` 和 `config_unchanged`。

2 m 是最后兜底距离，并非任意相对速度、遮挡、点云丢失或多机包围条件下的无碰撞保证。
高速度情况下需要依据实测延迟、机体尺寸和可用加速度提高触发距离，不能仅靠调整统计口径宣布成功。
