## 已完成

- 融合目标位置、速度、尺寸下限和协方差参与候选速度检查；动态约束可触发侧向/减速候选，保留原始几何保护。
- 限加速度过渡、执行延迟、连续分段 CPA 与最终命令复查；不可信速度和 stale 数据的保护。
- A* spawn 子进程，主安全回调非阻塞提交，目标版本/观测时刻检查，进程退出清理。
- 独立范围评估、合法最大匹配数、短时实际观测证据、重复目标限制、真值完整性、进入事件和滑窗/累计统计。
- 冻结风险/安全事件标签的混淆矩阵；无标签不伪造协议指标。
- Foxglove 实验面板、计数/百分比/表格/曲线/标记；配置版本迁移、JSON 导入导出、运行快照与 FOV 一致性检查。
- 最多 4 个独立客户端的受限并发真值采样，逐目标时间与完整性，自机碰撞信息查询。
- 4/32 机观察配置模板、最高 64 架配置容量、离线复算脚本和使用文档。

## 验证依据

1. 完整 Python 回归当前 127 项通过，包含真实 ROS 域 219 的话题传输测试和 Windows spawn 规划进程测试。测试域不连接 UE。
2. ROS 测试发送 2 架真值、1 架检测，指标正确发布 50%；停止检测而真值继续时检出数降为 0。
3. 动态检查覆盖未来横穿、分段间高速穿越、多目标无安全解和控制延迟；统计覆盖重复检测、关联切换、无输出、缺真值、迟到不回填及配置往返。
4. 浏览器 DOM 测试覆盖场景编辑、剖面点交互、文件导入后保存、三类配置导出、实时 50% 显示、强制停止按钮在普通停止忙碌时仍可用；TypeScript 检查和 Foxglove 扩展打包通过。未进行桌面 Foxglove 视觉验收。
5. 算法微基准：4,000 个几何点和 4/16/32/64 个合成融合目标，候选检查 P95 约 9.4/15.6/16.6/14.8 ms。不同障碍集合、唯一候选数和运行状态影响耗时，因此不是随目标数单调增长曲线；更不是 UE 多机全链路性能。原始结果保存在 reports/fusion_benchmark.json。
